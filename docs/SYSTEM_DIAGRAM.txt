                                 │
                                 ▼

                                 │
                                 ▼

┌─────────────────────────────────────────────────────────────────────────────┐
│                              DATA FLOW                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    CREATE POST FLOW:
    ─────────────────
    Admin Panel → POST /admin/panel.php
                    ↓
                CSRF Validation
                    ↓
                Input Sanitization
                    ↓
                mc_blog_admin_save()
                    ↓
                PDO Prepared Statement
                    ↓
                MySQL INSERT
                    ↓
                Redirect to Posts List

    VIEW POST FLOW:
    ───────────────
    User visits /blog-single.php?slug=my-post
                    ↓
                mc_blog_find_by_slug()
                    ↓
                PDO Prepared Statement
                    ↓
                MySQL SELECT
                    ↓
                Format & Escape Output
                    ↓
                Render HTML

    FILTER POSTS FLOW:
    ──────────────────
    User clicks category filter
                    ↓
                /blog.php?cat=windows
                    ↓
                mc_all_posts()
                    ↓
                mc_filter_posts_by_cat()
                    ↓
                mc_blog_paginate_slice()
                    ↓
                Render filtered results
